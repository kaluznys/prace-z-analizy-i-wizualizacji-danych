# prace-z-analizy-i-wizualizacji-danych
Prace dzielą się na dwie grupy:
- raporty z rozszerzeniem html wygenerowane przy użyciu analiz dokonanych przy użyciu kodu w języku python i narzędzia Markdown
- notebooki (głównie w Google Colab) zawierające kod, a także tekst, który jest analizą i interpretacją wyników.

W repozytorium znajdują się (w celu szybkiego dostępu do nich) pliki z danymi do analiz o rozwinięciach csv.
